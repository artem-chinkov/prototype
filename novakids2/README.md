# Novakid Learning Adventures 2.0 — Pandy Adventure Loop

Мобильный интерактивный демопрототип Kids Area: `https://artem-chinkov.github.io/prototype/novakids2/`.

## Демонстрационный сценарий

Главная → Карта → Magic Shop (3 речевых шага) → Открытие Fruit Rush → Выбор одного из 3 оформлений → Игра с управляемой корзинкой → Очки и награды → Мой мир → Выбор следующего сюжетного пути.

- Учебная миссия: +15 ⭐ только за первое завершение.
- Fruit Rush: +5 ⭐ за первую успешную игру в локальный день, дальнейшие повторы бесплатные.
- Коллекционный предмет «Волшебная лампа» появляется в комнате после первой успешной Fruit Rush.
- Звёзды тратятся на косметические предметы и облик героя; подсказки Pandy всегда бесплатны.
- Недельная цель: образовательная практика в **три разных дня**. В разделе «Награды» есть переключатель демодаты для проверки этого механизма. Повтор учебной миссии доступен на экране учебных результатов.
- Кнопка «Начать сценарий заново» в «Наградах» сбрасывает демоданные после подтверждения.
- Весь прогресс локален в браузере (`localStorage: novakids2-pandy-adventure-v2`). Записи детской речи не хранятся.
- Речевые шаги используют Web Speech API там, где он доступен. Для показа без разрешения на микрофон есть явно подписанный деморежим, который не оценивает произношение.

## Структура

- `index.html` — стартовый документ, относительные ссылки на ресурсы.
- `style.css` — мобильный интерфейс, анимации, адаптация размеров.
- `art.js` — оригинальные векторные иллюстрации на SVG: персонажи, локации, комната и предметы.
- `app.js` — экраны, состояние, сохранение, управление и игровой цикл Fruit Rush.

Нет внешних runtime-библиотек, бэкенда или ключей API. Google Fonts используется опционально с системным fallback.

## GitHub Pages

Текущий `.github/workflows/deploy-pages.yml` публикует дерево ветки `main`, включая эту папку. Прежний прототип в `/novakid/` и остальные проекты не изменены.

## Границы MVP

Настоящие Learning Engine, AI Game Director и авторизованная интеграция с уроками не подключены. Выбор следующей локации реализован на карте, а полноценная следующая образовательная миссия оставлена для будущего развития. Знаки и названия — демонстрационные, продуктовый прототип не заявлен как официальное приложение Novakid.
