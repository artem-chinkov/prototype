# RoomBudget

Мобильный интерактивный прототип 2D-планировщика комнаты с бюджетом.

**Сайт после активации GitHub Pages:** https://artem-chinkov.github.io/prototype/roombudget/

## Возможности

- План комнаты со свободно изменяемыми размерами
- Перетаскивание мебели пальцем на телефоне или мышью на компьютере
- Привязка предметов к сетке 10 см
- 8 типов мебели, дублирование, поворот и удаление
- Точные размеры, координаты и цены выбранного предмета
- Подсветка пересечений и выхода за границы комнаты
- Бюджет, остаток, смета и печать
- Отмена и повтор действий (до 50 шагов)
- Автоматическое локальное сохранение в браузере
- Экспорт и импорт файла проекта \`JSON\`
- Адаптивная верстка для смартфона и рабочего стола

Стек: **HTML / CSS / vanilla JavaScript**. Сборка, backend, регистрация и ключи API не нужны.

## Первый запуск GitHub Pages

Этот репозиторий использует **GitHub Actions** для публикации. Если Pages ещё не включён, владелец должен один раз:

1. Открыть https://github.com/artem-chinkov/prototype/settings/pages
2. В разделе **Build and deployment** выбрать **Source → GitHub Actions**
3. Открыть https://github.com/artem-chinkov/prototype/actions/workflows/deploy-pages.yml
4. Нажать **Run workflow**, выбрать \`main\` и запустить

После успешной публикации сайт доступен по адресу https://artem-chinkov.github.io/prototype/roombudget/. Следующие коммиты в \`main\` будут автоматически запускать деплой.

## Ограничения

Цены и габариты демонстрационные. Проверяются только пересечения прямоугольных объектов и границы комнаты; проходы, препятствия, несущие стены, дверные дуги и требования строительных норм не рассчитываются. Проекты и изменения хранятся в \`localStorage\` текущего браузера; для переноса на другое устройство используйте экспорт JSON.

## Структура

- \`index.html\` — экран приложения
- \`styles.css\` — desktop/mobile оформление
- \`app.js\` — модель проекта, логика редактора и вычисления
- \`../.github/workflows/deploy-pages.yml\` — публикация на GitHub Pages
